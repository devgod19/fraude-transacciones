🔍 Detección de Fraudes en Transacciones Bancarias

Este proyecto usa Machine Learning para identificar transacciones sospechosas de fraude usando un dataset de Kaggle.

🧪 Dataset

El dataset se puede cambiar se encuentra en la carpeta data, no hago el trabajo de quitarlo por seguridad ya que es un ejemplo de Kaggle.

🚀 Tecnologías usadas

Python 3.11
Pandas
Scikit-learn
Imbalanced-learn (SMOTE)
Matplotlib / Seaborn
📊 Modelos implementados

Regresión Logística
git clone https://github.com/devgod19/fraude-transacciones.git 
cd fraude-transacciones
python -m venv venv
source venv/bin/activate # o venv\Scripts\activate en Windows 
pip install -r requirements.txt
